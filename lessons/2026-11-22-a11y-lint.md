# Accessibility lint rules on, and TypeScript 7 everywhere, 2026-11-22

## What

- Four jsx-a11y rules that were off since the oxlint move are on: click-events-have-key-events,
  no-static-element-interactions, no-noninteractive-element-interactions, media-has-caption.
- The lightbox's top bar, media and bottom bar each had `onClick={stopPropagation}` only so the
  backdrop click would not close it. They now carry `data-lightbox-keep`, and `closesLightbox`
  (`src/lib/lightboxBackdrop.ts`, with a test) ignores clicks inside them. The prev, next and
  close buttons still stop their own clicks.
- The two backdrop clicks (lightbox, ConfirmDialog) keep a disable comment naming Escape as the
  keyboard path. The three media previews keep one saying no caption track exists to offer.
- The sign-in `<a>` names `href` after its spread, so it reads as a link.
- `prefer-tag-over-role` stays off for good. All 19 hits were correct roles on divs, and each
  swap it asks for changes the look or the behaviour: `<fieldset>` adds a border and
  `min-width: min-content`, `<dialog>` needs `showModal`, and `<progress>` brings native styling.
- `typescript` is 7. `next build` type-checks through `experimental.useTypeScriptCli` (2.0 s), and
  `next.config.ts` still loads. TS 6 remains only as `typescript6` for `scripts/i18n-deep.mjs`.

## Mistakes

- The first lightbox edit removed the `stop` helper along with the wrappers. The prev, next and
  close buttons call `stop(e)` themselves, so the next click on one would have closed the
  lightbox. The edit script's match-count guard stopped it before anything was written.
- Put the disable comments on the `onClick` attribute line. These rules report on the element's
  opening line, so the first lint run showed the comments unused and the hits still there.
- An explicit `href` before `{...link}` is TS2783 (overwritten by the spread). After the spread
  is fine.

## What worked

- Counting hits per rule with a throwaway config before deciding anything. 19 of 32 were the
  one rule worth keeping off.

## Rules

- An oxlint disable comment goes on the line above the element the rule reports, which is the
  opening tag, not the attribute.
- No `onClick` only to stop propagation. Mark the area and let the one handler check it.
