# The 100 that hid 607 KiB

## What
Lighthouse already said 100 on mobile and desktop, so the work was in what the
score does not punish. `pnpm perf` now audits the static export with Brotli and
fails on a CLS over 0.01. Links prefetch on intent through `IntentLink`, so the
homepage dropped from 607 to 269 KiB and a landing page from 905 to 266 KiB. CLS
is 0 on every route, mobile Speed Index equals FCP, and `/pro` accessibility and
Best Practices are 100. The Pro-only batch panel no longer ships to free visitors.

## Mistakes
- **The first audit deadlocked itself.** `spawnSync` froze the process that was
  also serving the page, so Chrome waited on a server that could not answer. It
  read as a Chrome crash and cost a 500 s run.
- **Batch edits silently did nothing on a CRLF file.** Multi-line matches missed
  `InstallPrompt.tsx`, the build passed, and the audit showed unchanged CLS. A
  replace that can miss must throw.
- **A floating install card fixed the CLS and covered the paste bar** on a short
  phone. Every number was green. Only a 320 px screenshot showed it. The card went
  to the end of the hero instead, then a second screenshot caught its text
  squeezed into a strip.
- **`position: fixed` on a `.surface` does nothing**: unlayered CSS beats utilities.
- **`experimental.inlineCss` looked like a free 180 ms and was worse**: FCP rose
  from 905 to 988 ms because the CSS lands in both the HTML and the RSC payload
  (168 to 464 KB raw). Measured, then reverted.
- **A comment on `/account` claimed the skeleton swap happens before paint.** On a
  static export the prerender paints first, and that swap was CLS 0.16.

## What worked
- Reading `network-requests` instead of the score: the heaviest item was prefetch.
- A phone-speed Chrome probe logging layout-shift rects; fast local loads hid it.
- Diffing the no-JS DOM against the hydrated DOM named the element at once.

## Rules
- A perfect score is not a finished page. Read the request list.
- Anything that arrives after hydration must not sit above content in the flow.
- `next/link` only through `IntentLink`; a test enforces it.
- Screenshot at 320 px before calling a layout change done.
- Audit fails on a `/account` SEO of 69 by design: it is `noindex`.
